# AI Professional presenters

Version 1.2.1 uses neutral presenter identifiers so the visual can be changed without rewriting the AI Professional workflow.

- `presenter-default` — active production presenter in `avatar.css`.
- `presenter-alt` — reserved alternate presenter identifier for a future Voice & Appearance selector.

The prior female presenter remains preserved in the repository history immediately before the Version 1.2.1 `avatar.css` update. It can be restored or promoted to `presenter-alt` in a later release.
